대한민국 초등학교 담임교사의 교실 생활을 다루는 반오픈형 3D 시뮬레이션 RPG입니다.

- 현재 버전: **1.0.0-beta.8 · 정식 베타**
- 만든이: **도구리** · 소속: **홍북초등학교** · 연락처: **raccoon@ai.cne.go.kr**
- 기획 기준: **PRD v0.5**의 구현 계약과 최신 사용자 확정 요구. PRD v0.4는 원안·출처를 보존한 역사 문서입니다.
- PC/모바일 웹, WebGL 2 사용. 게임 상태는 이 기기 브라우저에 저장하며 JSON으로 내보내고 가져올 수 있습니다.
- 개학 전 학교교육과정 확인 후 3월~다음 해 2월을 운영하고 다음 학년도 배정·전근으로 이어갑니다. 시작 가상학년도는 2030년입니다.
- [최신 PRD v0.5](docs/PRD_v0.5.md), [정식 베타 구현 범위와 검증](docs/BETA_SCOPE.md), [개발·검증·배포 안내](docs/DEVELOPMENT.md), [기획 원문 PRD v0.4](docs/PRD_v0.4.md).
- 공개 게임: [오늘 우리 교실은 · GitHub Pages](https://doguri25.github.io/class/). 접속하면 게임이 바로 열립니다.
- 기존 실행 사이트: [오늘 우리 교실은](https://classroom-days.anyconium.chatgpt.site). 두 사이트의 브라우저 저장 공간은 별개이며, 설정에서 JSON을 내보내고 가져와 기록을 옮길 수 있습니다.

## 정식 베타 beta.8의 변경점

게임 이름을 **오늘 우리 교실은**으로 바꿨습니다. 학생 말풍선·대화에 상황별 이모지를 표시하고 학교톡에 이모지 선택기를 추가했습니다. 날짜·시각·학생/교직원/보호자 이름은 굵기와 색으로 함께 강조하며, 기존 질문의 중복 방지와 작은 사진을 유지합니다.

PRD의 자동 저장 3개·수동 저장 3개를 구현했습니다. 날짜·학급·예산·기록 수를 미리 확인한 뒤 불러오며, 손상된 마지막 저장은 자동 덮어쓰기를 멈추고 다른 정상 기록에서 복구합니다. 복구 시 원본 묶음을 보관하고 저장 공간 부족은 지속 안내합니다. 저장은 현재 기기 안에서만 이루어집니다.

GitHub Pages는 루트의 index.html에서 dist 게임으로 자동 이동합니다. .nojekyll로 정적 파일을 그대로 배포하며, 기존 main 브랜치의 Pages 자동 배포를 사용합니다. 별도 로그인·외부 서버·추가 시작 버튼은 필요하지 않습니다.

## 정식 베타 beta.7의 변경점

- 읽기 안내 뒤 실제 버튼을 따라 배우는 실습 8단계와 건너뛰기·접기·재시작을 추가했습니다.
- 연속 선택·저장·돌아가기 후 읽던 위치를 유지합니다. 학생 말풍선 사진을 더 줄였습니다.
- 생활 흔적 5종, 학생 1인 1역의 참여와 정리, 수업 후 교사의 5/10/20분 청소를 연결했습니다.
- 수업 뒤 회의와 10/20/30분 학급·행정업무, 연가 21일·병가 7일·조퇴·병조퇴를 추가했습니다. 8시간을 1일로 계산하는 사용자 지정 게임 규칙이며 인계·승인·잔액·취소·연도 보관을 지원합니다.
- 학년/교과 조합 54개에 창작 수업 카드 120개를 집필하고 칠판·학생 질문·질문지·피드백을 연결했습니다. 모든 성취기준과 연간 차시를 완성한 것은 아닙니다.

PRD 12장에 실행 조건·시간·저장·실패 경로를 구체화했습니다. [GitHub 소스](https://github.com/doguri25/class)의 기존 공개 설정과 실행 사이트의 기존 접근 범위를 유지합니다.

## 정식 베타 beta.6의 변경점

PRD를 32개 기능별 실행 계약, 12개 공통 불변 조건, 28개 인수 시나리오, 기존 115개 수용 기준 연결표와 12개 남은 개발 묶음으로 구체화했습니다. 입력·시간·상태·저장·예외·검수 기준을 분리하고 다중 저장 슬롯, 실제 지역 규칙, 전체 차시 콘텐츠와 모바일 실기기 검수 등 미완료 범위를 명시했습니다. 게임 규칙·저장 구조는 beta.5를 유지합니다.

게임 정보창과 제작 기록에서 목차 있는 PRD 페이지를 열고 Markdown 원문·구현 범위·개발 안내를 내려받을 수 있습니다. `node scripts/publish-docs.mjs`로 원문과 배포 문서를 함께 갱신하고 `--check`로 일치를 확인합니다. GitHub `doguri25/class`는 요청된 연결 대상이며 생성·푸시는 실제 원격 확인 전 완료로 표시하지 않습니다. 문서·Sites 배포와 GitHub 작업의 성공을 구분합니다.

## 정식 베타 beta.5의 변경점

진행 입력은 상황별 보기→기타 직접 입력으로 바꾸고, 모바일 안내와 먼저 말 거는 카드를 화면 위로 분리했습니다. 초안·개인 메모와 기존 저장을 유지합니다. 고유 삽화 NPC 6명, 전문 분야·제약·담당 공간, 업무별 18개 대화 주제, 학교톡 개별 연락·근무 시간 회신, 협의 요청→일정→현장 참석→후속 기록, 자율 봉사의 학교 지원 배정→활동 결과→확인을 연결했습니다. 시간대별 채광·발밑 그림자와 삽화에 맞는 NPC 외형을 적용했습니다. 144개 Node 검사와 신규/기존 실제 앱 DOM 흐름을 확인했으며 모바일 실기기 시각·성능 QA는 별도입니다.

## 정식 베타 beta.4의 변경점

말풍선 사진 축소, 학교교육과정 확인 후 스크롤 유지, 모바일 새 학급 설정 압축을 적용했습니다. 7단계 튜토리얼은 건너뛰기·이전/다음·진행 저장·다시 보기를 지원하며 게임 시간을 소비하지 않습니다. 보조도구의 점검 필요 반납→사용 중지→행정실 요청→학교톡/일정→수령 확인→재대여를 연결했습니다. 기존 beta.3의 2월 말 진행 복구는 유지합니다.

## 정식 베타 beta.2의 변경점

캐릭터의 얼굴·머리·의상·관절과 상황별 동작, 학생 삽화 32종을 고도화했습니다. 총 240종 일상 소재와 관계/학년 반응, 인물 관계, 보호자별 권한·형제자매·전입전출, 개인 물건·동의·분실물·후속 일정, 실제 전교 투표·위원 선출·봉사 대체, 시간을 사용하는 평가·전담 확인, 모든 업무 스킬의 준비 효과·휴업 보완·증빙 점검·선도사업 재지정, 책 12권 삽화와 사서/가상 작가 협의를 연결했습니다.

127개 모델·실제 Three 기하/경로·저장·릴리스 검사와 기존/신규 DOM 클릭 흐름을 확인했습니다. 실제 모바일 시각·성능과 모든 지역 행정 지침이 검수됐다는 뜻은 아닙니다. 범위 및 남은 세부 항목은 BETA_SCOPE를 확인하세요.

## 정식 베타 beta.1의 변경점

학교교육과정 선행 확인, 학년별 입학식·개학식·졸업식, 두 학기 학사 일정·생존수영·학예회·장터·체험학습, 학생 지원·출결 서류, 12권 온책읽기·대출, 60종 준비물 주문·입고·환불, 교사 연수·출장·감사·선도사업, 행동특성 검토·정정, 다년 배정·전근·재회를 연결했습니다. 실제 구현과 축약 모형 및 남은 정식판 검수는 BETA_SCOPE에 구분합니다.

수정할 때마다 `node scripts/release.mjs --next "변경 내용"`으로 번호를 올립니다. 새 체크아웃은 `git config core.hooksPath .githooks`를 실행하면 게임 변경 시 버전 누락을 커밋 훅이 보완합니다. 날짜와 최근 3개 변경은 게임 정보창에 표시합니다.

## 요타의 변경점

1. 학급업무 → 학급교육과정에서 3월 안에 우리 반 목표·학생 지원·과목별 수업 방법·공간·준비물·평가 점검일과 창체 세 영역을 계획합니다. 마지막 3월 등교일의 마감과 학교톡 알림이 생성되며, 수업·회의와 겹치지 않는 20분에 확정합니다. 초안을 저장하고 수정 이력을 게임 날짜로 남기며 교사 PC의 편집 가능한 계획서로 만들 수 있습니다. 늦은 기존 저장은 기한 후 보완으로 실제 제출 날짜를 보존합니다.
2. PRD의 계획·변경 계획·실시·미실시 시수 장부를 데모 기간 안에서 구현했습니다. 운동회로 대체한 오전 수업은 변경 계획에서 조정합니다. 미실시 차시의 핵심 목표를 앞으로 있을 같은 과목의 담임 수업에 연결해 다시 다룰 계획을 세울 수 있습니다. 실제 다음 차시를 수업해야 완료되며, 지나간 수업이나 시수를 소급 생성하지 않습니다.
3. 과목별 평가 점검일을 개인 일정에 연결합니다. 확정한 목표·학습 증거에 맞는 실제 수행평가 기록만 학생별 점검 인원에 포함합니다. 목표나 증거를 바꾸면 새 계획에서 다시 확인하며, 미실시는 평가 완료로 세지 않으며 당일 결석자의 새 평가 결과 입력은 막습니다. 계획만 세워서는 성적·예산이 변하지 않습니다.
4. 학급업무(수업·평가·학부모 소통·학급 활동)와 행정업무(공문·업무분장 계획·회의·연수·시설 요청)를 별도 메뉴로 나눴습니다. 교사 PC에서도 두 업무 영역으로 바로 이동합니다.
5. 시간표를 하루/주간 보기로 바꾸고 요일을 탭으로 선택합니다. 아침, 1–4교시, 점심, 5–6교시를 한 화면에 표시하며 작은 세로·가로 화면과 큰 글자 설정에 맞춰 전용 압축 배치를 적용합니다. 전담은 푸른 칸, 수업 없는 시간은 빈칸으로 구분하고 방과후·늘봄은 개인 일정에 유지합니다.
6. 쉬는 시간 자유 이동과 수업 시작 시 자리 복귀 속도를 15% 줄였습니다. 학생별 목적지·대기·8방향 선택과 가구 회피는 유지합니다. 즉시 장소 이동에 걸리는 게임 시간과 교사 조작 속도는 그대로입니다.
7. 원목 질감·얕은 표면 요철, 둥근 책상·의자·가구, 캐릭터 눈·표정·머리카락·옷의 세부, 운동장 잔디 무늬와 골대 그물을 추가했습니다. 과한 밝기를 낮추고 따뜻한 햇빛·차가운 보조광과 공간 크기에 맞는 그림자를 적용했습니다. 화면 폭에 맞춰 그림자와 출력 해상도의 상한을 조정합니다.

## 세타의 변경점

1. 교실 책상 위 PC 또는 왼쪽 ‘교사 PC’에서 업무 바탕화면을 엽니다. 스티커메모, 공문함, 회의록, 학생명렬표, 내 문서, 학교톡, 개인 일정, 평가·관찰, 가정통신문을 같은 화면에서 전환합니다.
2. 개인 스티커메모의 제목·내용·색·고정·보관과 복원을 지원합니다. 입력은 자동 저장하고 최초 작성일과 수정일을 게임 날짜로 보존합니다. 메모를 적는 것만으로 공식 학생 기록이나 관계 수치는 바뀌지 않습니다.
3. 주마다 두 공문이 접수됩니다. 요청 확인 → 문서 초안 작성·붙임 선택 → 5분 기안 상신 → 게임 시간 경과 후 교감 검토 → 보완과 재상신 또는 결재 → 2분 최종 제출로 이어집니다. 작성란이 비어 있거나 붙임이 빠지면 보완 의견이 학교톡으로 오며, 마감일은 개인 일정에 표시합니다. 단순 안내문은 2분 공람으로 완료합니다.
4. 명렬표는 실제 학급 학생을 불러오며, 회의록은 참석을 완료한 회의의 일시·장소·안건·협의 내용과 후속 준비만 불러옵니다. 계획서·수업자료·기타문서를 편집하고 텍스트로 내려받을 수 있습니다. 상신 시점의 첨부본은 고정되어 이후 원본 수정으로 바뀌지 않습니다.

이 버전은 첫 10주의 학급 생활을 체험하는 단계입니다. 전근·다음 학년도·졸업 후 재회·운동회 외 학년도 전체 행사·생존수영·학생대회와 전교선거·감사·선도학교 과제·법정의무연수 판정·중대 사안 절차는 후속 범위입니다. 전 과목의 모든 학년별 차시 대본, 전체 도서 원고와 모든 특별실의 집단 이동도 아직 구현하지 않았습니다. 이번 수업 장면은 교과의 특징을 표현하는 창작 데모이며 실제 교육과정의 단원 순서나 성취기준 전체와 대응하지 않습니다.

학교톡은 작성한 대본과 키워드·상태 분기로 답합니다. 외부 AI 호출이나 실제 학교에 메시지를 보내는 기능은 없습니다. 시간표와 출결 서류는 간소화한 모형입니다. Google Fonts를 불러오지 못하면 기기 기본 글꼴로 표시합니다.

알파·베타·감마 저장은 schema 4로 변환합니다. 델타 저장은 그대로 이어서 사용하고 엡실론 필드를 추가합니다. 기존 메모·관계·대화·질문 노출 이력을 유지하고 이동 중 저장은 목적지에서 이어지며, 구입한 준비물은 재고로 옮깁니다. 제타의 운동회 기록은 선택 필드로 추가하여 이전 저장과 이어집니다. 에타는 교구 선택·반납 기록을 추가하고, 예정된 학년회의의 장소를 교사연구실로 옮깁니다. 완료된 회의의 원래 장소는 보존합니다. 세타는 교사 PC 자료를 선택 필드로 추가해 기존 학급 저장을 이어받습니다. 요타는 학급교육과정을 선택 필드로 추가하고 기존 상태를 유지합니다. 별도 계정 동기화나 서버 저장은 없습니다.

## 조작

바닥 클릭, WASD/방향키 또는 터치 조이스틱으로 이동합니다. 인물을 누르면 접근해 대화합니다. `+`/`−`·휠·핀치로 50–200% 확대하며 확대율 버튼/0 키로 초기화합니다. Shift+드래그, 오른쪽 드래그, 두 손가락 이동으로 화면을 살펴봅니다. 인물·문서 창이 열리면 시간이 멈추고, 브라우저 뒤로가기는 열린 창부터 닫습니다.

상단 날짜 또는 왼쪽 ‘내 일정’으로 스케줄러를 엽니다. 회의에 참석하려면 해당 날짜의 수업 후 시작 시간 전에 장소로 이동한 뒤 참석 기록 버튼을 누릅니다. 준비할 내용과 참석 후 기록은 일정 메모와 교사 인물 메모에 남습니다.

급식은 점심시간, 체육은 해당 교시의 수업 버튼으로 출발합니다. 즉시 도착한 장소에서 이동 이야기에 답하고 활동합니다. 복귀 버튼을 누르면 바로 교실로 돌아옵니다. 운동장 놀이는 아침/쉬는 시간에 10분 이상 남았을 때 시작합니다. 현장 활동의 짧은 애니메이션은 상단 배속과 별개입니다.

학급 업무 또는 우리 반 → 학급 선거·자치에서 선거를 열 수 있습니다. 단계를 나누어 진행할 수 있으며 다음 수업 시간을 넘기지 않습니다. 데모의 첫 학기 선거 1회를 체험합니다. 동점은 공동대표, 무후보는 공동 자치 활동, 단독 후보는 참여자의 과반 찬성으로 정하는 가상 학급 규칙입니다.

교사 PC의 공문 결재는 가상 학교의 간소화된 업무 모형입니다. 실제 K-에듀파인·업무관리시스템·나이스와 연동하지 않습니다. 입력 저장은 무료 시간이지만 기안 상신·공람·최종 제출은 게임 시간을 사용하며 담임 수업이나 회의 시간을 넘기지 못합니다.
