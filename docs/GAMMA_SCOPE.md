## 데모의 운영 규칙

- 기본 평일 50일, 10주입니다. 기초학력지도 계획이 늦게 시작되면 마지막 예정 회차가 있는 주까지 연장하며 최대 100일입니다. 법정 수업일수나 실제 공휴일 달력을 모델링하지 않습니다.
- 기초학력지도는 예정 15:00–15:40이며, 같은 날 16:00까지 시작할 수 있습니다. 예정 주에 실행하지 않은 회차는 미실시로 남습니다. 보강 일정 변경은 후속 범위입니다.
- 학습지원 예산은 사용자 요청에 따른 게임 규칙입니다. 실제 국가 공통 예산이나 특정 학교의 예산으로 표시하지 않습니다.
- 지도 대상 학생의 개인 일정에 지도 요일을 표시합니다. 방과후·늘봄은 계속 학생의 개인 일정으로 관리하며 학급 시간표에 넣지 않습니다.
- 직접 대화와 학교톡은 작성된 문장에 상태·키워드 분기를 적용합니다. 외부 AI 호출이나 실제 교직원/학부모에게 메시지를 보내는 기능은 없습니다.
- 매회 동일한 주제를 플레이어가 직접 고르는 대화는 의도적으로 다시 열 수 있습니다. 자동 학생 요청은 본 질문 기록으로 중복 알림을 막습니다.
- 노트와 기억은 게임 날짜로 유지합니다. 다음 학년도나 다른 학교로 넘기는 다년 플레이는 아직 제공하지 않습니다.

## 후속 구현 범위

전체 학년도 행사·운동회 종목/대표·선거/학생회·생존수영·체험학습 장소/교통·전근·졸업 이후 재회·학년도별 교육과정 시수 검증·법정 의무연수 판정·학교폭력/교권침해/감염병의 정식 사안 절차·정기 감사·선도학교 과제·모든 특별실의 전용 활동·교과별 전체 차시 대본은 PRD에 유지합니다. 이번 감마가 해당 기능 전체를 완성한 것은 아닙니다.

## 검증 범위

Node 모델·실제 Three.js 장면의 이동/형상 검증 36개와 DOM 조작 흐름을 확인했습니다. DOM 확인에는 2배속, 삽화 선택, 다회 대화, 보호자별 메신저, 지도/통신문/상담, 200% 글자 설정과 모바일 확대 버튼의 CSS 위치가 포함됩니다. 실제 브라우저 렌더링과 실기기 성능 검증은 별도입니다.
