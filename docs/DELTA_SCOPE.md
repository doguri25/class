## PRD에서 추가한 기능

- 격주 학년회의: 해당 지역의 한 학년 학급 수가 1이면 생성하지 않는다.
- 3주 간격 수업 나눔 모임: 학교톡 초대 → 일정 확인 → 참석/불참 → 장소 방문 → 기록.
- 전직원회의를 스케줄러에 통합. 담임 수업이 남아 있으면 참석 버튼으로 건너뛸 수 없다.
- 기초학력지도 10회/학부모 상담을 같은 일정표에 표시하고 예약 충돌을 확인한다.
- 학기 초 업무계획: 업무·목표·실행 항목 최대 6개·점검일을 저장하고 체크한다.
- 1인 1역: 학생별 역할을 12종 중 선택한다. 이름·날짜 메모와 관계 시스템은 기존 기능을 사용한다.

## 판정과 저장

- 같은 상대에게 같은 문장을 보냈는지는 공백·문장부호를 정규화해 비교한다. 서로 다른 보호자에게 같은 안내를 보내는 것은 허용한다. 가정통신문·정해진 업무 알림은 이 문답 제한과 별도다.
- 수업 준비물 지원 효과는 관련 물품이 하나 이상 있으면 +1이며, 여러 물품을 사도 무제한 중첩하지 않는다. 관련 소모품은 한 수업에 한 종류의 1회분만 사용한다. 전원 결석이면 소모하지 않는다.
- 회의는 현재 생성된 일정에 대해 겹침을 경고한다. 이후 도착한 새 초대가 기존 일정과 겹치면 조정할 수 있다. 전체 학년도 학교 일정 엔진은 후속이다.
- schema 1–3 저장을 4로 옮긴다. 기존 구매는 품목별 재고로 복원하고, 시작한 문답·인물 메모·질문 이력·대열 이동을 유지한다.
- 학교톡은 대본/키워드/현재 상태를 사용하는 로컬 시뮬레이션이며 외부 발송이나 생성 AI 연결은 없다.

## 남은 범위

연간 행사의 전체 진행, 다음 학년도·전근·재회, 학생 선거/대회, 생존수영, 중대 사안 처리 절차, 감사와 선도학교, 법정 기준의 상세 검증은 후속이다. 특별실 전부에 대한 학급 대열 이동과 학년별 실제 교육과정의 모든 차시 대본도 후속이다. 이번 교과 장면은 창작 예시이며 성취기준/단원 번호와 일대일 대응을 주장하지 않는다.

검증: 49개 모델/실제 장면 계산 검사와 별도 DOM/CSS 사용자 흐름 검증. 실제 브라우저·실기기 렌더링 검증은 수행하지 않았다.
