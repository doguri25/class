# beta.2 신규 삽화

2026-09-15. 이 게임을 위해 이미지 생성 도구로 새로 제작했다. 실제 학생 사진, 학교 명단 또는 기존 책의 삽화를 입력하지 않았다. 모든 인물·이야기는 가상이다. 아래는 생성 지시의 요약이다.

학생 삽화는 인물에 저장된 sheet/cell로 선택한다. 책 삽화는 library-life.js의 12권 순서에 따라 CSS의 3×4 셀로 표시한다. 원본 이미지를 뷰어로 확인한 뒤 사용했으며, 이번 작업에서 라이브 사이트 또는 모바일 브라우저 시각 검사는 수행하지 않았다.

기존 교사·교직원·보호자 삽화와 선택 화면은 유지한다. 게임 공간의 3D 캐릭터는 character-rig.js의 절차적 기하와 애니메이션으로 구현했으며 새 삽화를 3D 모델로 변환한 것은 아니다.
