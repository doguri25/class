## 학년회의 흐름

2개 반 이상인 학년에서 학교톡 초대가 스케줄러에 자동 등록됩니다. 진도·수행평가·교구·학생 참여 중 안건을 선택하고, 당일 담임 수업을 마친 뒤 시작 시간 전에 교사연구실에서 참석합니다. 다른 예약과 겹치면 먼저 조정합니다.

참석한 안건에 따라 동료의 응답과 회의 메모가 남고, 이틀 뒤 점검할 후속 준비가 자동 생성됩니다. 완료한 회의 이후 여유 시간 10분을 확보해 연구실에서 정리 내용을 입력하고 학교톡으로 공유합니다. 일정·교사 메모·동료 관계에 한 번만 반영하며, 완료 버튼은 다시 표시하지 않습니다.

한 학년에 한 반인 학교에는 학년회의를 만들지 않습니다. 예전 저장의 앞으로 열릴 학년회의는 연구실로 옮기고 학교톡으로 변경을 안내합니다. 이미 완료했거나 지난 회의의 원래 장소는 보존합니다. 전직원회의는 교무실입니다.

## 교구 사용

도착한 체육 장소에서 최대 3종을 고릅니다. 선택하면 실제 장면에 해당 도구 모형을 배치하고, 체육 수업에 활용 설명을 표시합니다. 활동 중에는 교구 변경을 잠그고 실제 사용 목록을 보관합니다. 체육 수업 기록에는 사용 도구 이름이 남고, 체육·놀이가 끝나면 자동 반납합니다. 대여·반납 최근 100건을 저장하고 창에서는 최근 10건을 보여 줍니다.

학교 공용 교구이므로 인당 6만 원 학급 예산을 차감하지 않습니다. 종목별 물리 미니게임이나 여러 학급의 재고 경쟁, 교구 파손·배송, 특별실 예약 엔진 전체는 후속 범위입니다. 학년회의의 교구 안건은 자료 준비를 연결하며 실제 예약 시간을 자동 변경하지는 않습니다.

## 소리와 조작

웹 오디오로 직접 합성하며 외부 녹음·음원 파일은 사용하지 않습니다. 최초 버튼 조작 후 활성화합니다. 설정에서 소리·음량·배경 연주를 조정하고 상단 스피커로 즉시 음소거할 수 있습니다. 기존 기기의 소리 끄기 설정을 보존합니다. 앱을 벗어나면 출력이 음소거되며, 시간 정지·모달 중에는 새 배경 음을 생성하지 않습니다. 짧게 시작된 음은 잔향이 끝나고 멈춥니다.

음악실에서는 피아노·맑은 종·리듬 북을 선택하고 음 버튼을 누릅니다. 별도 곡 악보나 음원은 포함하지 않습니다. 이 탐색 창을 열면 시간이 멈추고 수업 진도·성적은 자동 증가하지 않습니다.

## 저장과 검증

schema 4와 기존 저장 키를 유지합니다. 교구 상태와 이력을 선택 필드로 추가하고, 이전 저장을 불러올 때 기본값을 채웁니다. 인물 메모·관계·진도·선거·운동회·예산을 초기화하지 않습니다. 릴리스 스크립트로 날짜와 최근 3개 버전, 제작자 정보를 유지합니다.

- 모델·실제 Three.js 기하·이동·음향 제어 검사 70개 통과.
- 1/6학년 및 4/20/28명 배치의 앞 공간과 착석 충돌, 음악실 10개 의자/보면대의 방향을 수치로 확인.
- 연구실 회의 → 안건 → 참석 → 후속 준비, 테마 변경, 도구 선택 → 체육 수업 → 사용 기록 → 반납, 음량/음소거의 앱 버튼 흐름 확인.
- 320/375/390px 세로 및 844px 가로, 100/125/150/200% 글자 설정의 DOM·CSS 규칙 확인.
- 브라우저 렌더링·실기기 성능·스피커 청음 검증은 수행하지 않음. DOM 검증은 3D 렌더러를 대체하며, 기하 검사는 실제 장면 모델을 사용함.

기본 10주 데모의 범위를 유지합니다. 전근·다음 학년도·전체 연간 행사·생존수영·감사·선도학교와 법정 절차의 완전한 구현은 후속 단계입니다.
