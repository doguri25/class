기준: PRD v0.4 18.2–18.3 및 최신 모바일/이동 수정 요청. 기본 10주 데모 범위를 유지한다.

## 학급 선거와 자치

- 첫 학기 선거 1회. 공고 2분 → 출마 희망 최대 4명 → 동일 준비 기회 3분 → 후보별 질문/답변 → 공약 게시 또는 순서대로 발표 5분 → 비밀투표와 개표 5분.
- 학급문고·회의 참여·쉬는 시간 놀이·1인 1역 도움의 4가지 공약. 공약별 두 활동을 5분씩 실천하면 날짜 메모·학생 기억·학급 관계에 반영한다.
- 후보 질문은 한 번 확인하면 비활성화된다. 확정 결과와 완료 활동은 다시 실행해 중복 보상을 받을 수 없다.
- 무후보는 공동 자치, 단독 후보는 투표 참여자 과반 찬성, 동점은 공동대표라는 데모 규칙을 사전에 안내한다. 실제 학교의 전국 공통 규칙이라고 설명하지 않는다.
- 출마 희망 변경을 확인할 수 있다. 교사는 투표 대상을 직접 고르지 않으며 득표 계산에 성별·외모·가정환경·성적·교사와의 관계를 사용하지 않는다. 개별 학생의 선택은 공개하거나 저장하지 않는다.
- 결석 학생은 참여 인원/득표 합계/기억 변화에서 제외한다. 이미 하교한 학생이 있으면 다음 공동 활동 시간에 이어가도록 안내한다. 다음 수업 시작 시각을 넘기는 행동은 실행하지 않는다.
- 대표에게 명렬표 배지를 표시한다. 당선자만 활동하는 구조가 아니라 다른 학생도 공약 실천에 참여한다.

## 이동과 저장

대열을 실제로 기다리는 단계는 새 플레이에서 사용하지 않는다. 이전 이동 저장을 읽을 때 남은 구간의 시간과 도착 기록만 반영하며 재접속으로 시간이나 기록을 중복 추가하지 않는다. 식사·체육·놀이의 짧은 현장 활동은 유지한다. 쉬는 시간 자유 이동은 게임 시간이 흐르고 움직임 줄이기가 꺼진 경우에 적용한다. 학생을 눌러 대화하러 갈 때 대상 학생이 잠시 기다린다.

기존 schema 4를 유지하며 `civics`와 `travelSeen`을 추가한다. schema 1–3 변환, 메모·관계·학교톡·일정·재고 등 기존 자료를 보존한다. 선거 단계·후보·표 합계·공약 상태의 형식을 가져오기 전에 검증한다. 큰 글자와 이름 표시는 기기 설정으로 유지된다.

## 확인한 범위

- 모델/실제 Three.js 장면 계산 검사 56개: 즉시 이동, 이전 이동 저장, 시간/결과 중복, 결석 제외, 이동 사건 반복 방지, 선거/공약 상태 저장, 수업 시간 보호, 하교 후 전체 활동 제한.
- 28명과 기본·모둠·ㄷ자 배치에서 자유 이동 경로가 가구를 통과하지 않고 수업 시작 뒤 자기 자리로 돌아오는지 계산했다. 기존 착석·8방향·이름·드래그 검사도 포함한다.
- 별도 DOM/CSS 환경에서 실제 UI 동작을 연결해 즉시 이동 → 사건 응답 → 급식 → 복귀, 선거 → 문답 → 투표 → 실천을 확인했다. 기존 대화·학교톡·준비물·스케줄러도 확인했다.
- 320/375/390px 세로와 844px 가로의 100/125/150/200% 설정에서 반응형 CSS와 DOM 영역 분리를 확인했다. 이 환경은 레이아웃 렌더러가 없으므로 실제 브라우저/휴대폰의 픽셀 배치나 성능 검증을 대신하지 않는다.

## 후속 범위

전교 임원선거, 다음 학기 선거, 학교 단위 학생회 예산/회의, 학생이 작성하는 포스터 편집, 다음 학년도·전근·재회, 전체 연간 행사, 생존수영, 학생대회, 감사·선도학교, 법정 기준 및 중대 사안 절차의 상세 구현은 후속이다. 이번 추가는 학급 선거와 공약 실천의 체험이며 PRD 전체 구현 완료를 뜻하지 않는다.
